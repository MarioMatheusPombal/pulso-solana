# PULSO · README assets and motion kit

**NOT AUDITED · DEVNET DEMONSTRATION ONLY**

This folder extends the [brand kit](../README.md) with two things: the images the READMEs use (`../../readme/`) and the pieces a video needs (`layers/`, `previews/`, `motion-tokens.json`). There is no Remotion project here yet. These are the inputs for one.

Everything is generated by one script with no dependencies:

```sh
node public/assets/brand-v1/motion/build.js
```

The Guardian art is embedded from two reduced copies of the masters in `../raster-v2/` (`layers/guardian-mark-400.png`, `layers/guardian-heart-520.png`, 160-colour palette). Videos should load the full 1254 px masters instead.

## The one idea

**A flat line means the agent acts alone. The line beats only where a human approves.**

Every asset uses the pulse line this way. Autonomous transfers get a straight green line. An approval gets a beat. A rejected attempt gets a beat, then a broken red line and a cross. Do not add a beat for decoration.

| File | Size | Shows |

| `hero-*.svg` | 1200 × 400 | Wordmark, tagline, Guardian, pulse line |
| `flow-*.svg` | 1000 × 520 | The three outcomes of an action: executed alone, executed after approval, rejected |
| `primitive-*.svg` | 1000 × 340 | Ten fields bound into one `action_hash` |
| `scenarios-*.svg` | 1000 × 420 | Demo scenarios A–F and the result each must produce |
| `divider-*.svg` | 1200 × 36 | Section divider |
| `docbar-*.svg` | 1200 × 96 | Slim header for docs and package READMEs |
| `footer-*.svg` | 1000 × 240 | Closing line with the full Guardian |
| `social-preview.svg` / `.png` | 1280 × 640 | GitHub social preview and Open Graph image |

The SVGs animate with CSS only (a light running along the line, the eyes glowing). With `prefers-reduced-motion` the animation stops and the image is complete as drawn. Text uses system fonts, so widths vary a little between platforms.

`social-preview.png` is a screenshot of the SVG. To re-export:

```sh
chrome --headless=new --window-size=1280,640 --screenshot=social-preview.png social-preview.svg
```

GitHub has no API for the social preview. Upload the PNG by hand in each repository under Settings → General → Social preview.

## Motion layers (`layers/`)

Transparent SVGs with stable ids, so a composition can animate one element without redrawing the rest.

| File | Ids | Use |
|---|---|---|
| `pulse-line.svg` | `pulse-idle`, `pulse-beat` | Draw with `stroke-dashoffset`; both paths have `pathLength="1"` |
| `hood-outline.svg` | `hood` | Stroke-draw around the Guardian. Same 1254 px space as the master |
| `hood-mask.svg` | `hood-mask` | Iris wipe or reveal mask, same space |
| `eye-glow.svg` | `eyes`, `eye-left`, `eye-right` | Overlay on the master to make the eyes ignite |
| `grid-dark.svg`, `grid-light.svg` | `bg`, `grid-lines` | Backdrop |
| `notice-bar.svg` | `bar`, `notice` | Amber bar with the notice, 1920 × 56 |
| `lower-third.svg` | `lt-eyebrow`, `lt-title`, `lt-tick` | Caption panel |
| `badge-*.svg` | `badge-bg`, `badge-glyph`, `badge-label` | The five states: autonomous, awaiting, confirmed, rejected, expired |
| `payload-card.svg` | `v-action` … `v-action-hash`, `btn-approve`, `btn-deny` | Approval card frame. The value slots are empty on purpose |
| `scenario-A.svg` … `scenario-F.svg` | `letter`, `title`, `subtitle`, `pulse`, `status`, `notice` | Title card per demo scenario, 1920 × 1080 |

The payload card has the same nine labels as the approval screen in `app/components/ApprovalScreen.tsx`. Fill the values from a real request. Do not invent them.

## Tokens (`motion-tokens.json`)

30 fps. Durations are in frames.

| Token | Frames | Use |
|---|---:|---|
| `uiFast`, `uiBase` | 6, 7 | Surface and focus changes (the 180–240 ms from the brand guide) |
| `enter`, `exit` | 12, 8 | Elements arriving and leaving |
| `lineDraw` | 30 | Pulse line across the frame |
| `hoodDraw` | 28 | Hood outline trace |
| `beat` | 14 | One beat |
| `hold` | 45 | Minimum time a payload stays still on screen |
| `heartbeatLoop` | 72 | Idle loop |

`easing` holds cubic-bezier control points, `spring` holds configs in the shape Remotion's `spring()` takes, and `paths` holds the pulse and hood path data for `evolvePath` from `@remotion/paths`. `guardian.eyes` gives the eye centres in master pixels.

## Rules

1. Payload values never animate, scramble or scroll while they are on screen for review. Bring the card in, then hold.
2. Green appears only after an observed result. Amber means a decision is waiting. Red means a known rejection. Expired is neutral.
3. Every state has its word on screen. Colour alone is not a state.
4. The notice stays visible for the whole duration of every composition.
5. No plague humour, skulls, crosses, shields or padlocks. The Guardian watches. It does not threaten.

## Storyboards

**Logo sting, 3 s.** Line draws from the left (0–1 s). Hood outline traces as the beat lands (0.7–1.6 s). Guardian fades in at 94% scale and settles, eyes ignite (1.1–2 s). Wordmark rises 28 px (2–2.6 s). Hold.

**Approval cut, 20 s.** Follows the storyboard in the brand guide, section 11.

| Time | Scene | Layers |
|---|---|---|
| 0–3 s | Agent requests an action | `scenario-B`, `pulse-line` idle |
| 3–8 s | Exact fields appear and stay still | `payload-card`, `badge-awaiting` |
| 8–13 s | Person reviews the payload | `payload-card` held, `eye-glow` |
| 13–16 s | Single-use approval | `btn-approve`, `pulse-beat` |
| 16–20 s | Result observed, notice | `badge-confirmed`, `notice-bar`, closing still |

**Attack cut, 15 s.** One scenario card each for C, D, E and F, about 3 s apiece: title in, line draws to the beat, breaks, cross and error code appear, `badge-rejected` (use `badge-expired` for F). Close on the Guardian with "The agent can never widen its own authority."

Scenes that show the product must use recordings of the implemented behaviour. The layers frame those recordings. They do not replace them.

## Using the layers in Remotion

Copy this folder and `../raster-v2/` into the Remotion project's `public/` directory and load files with `staticFile()`. Read `motion-tokens.json` for timing, easing and path data instead of retyping numbers. Compose at 1920 × 1080; for 1080 × 1920 and 1080 × 1080 use the safe areas in the tokens file.
